Space Invaders OMV Remake – An enhanced Python/Pygame version of the classic arcade shooter.

Controls:

    ←/→ – Move

    ↑/↓ – Change depth (zoom)

    Insert – Fire weapon

    Delete – Cycle weapons

    1–5 – Direct weapon selection

    Right Shift – Restart after Game Over

    For MAcOs:

    To remove the game from gatekeeper quarantine do on the terminal

    xattr -d com.apple.quarantine /path/to/MygameFile.app
